| Priority | ID | Issue | Detail | Impact | Required fix |
|---|---|---|---|---|---|
| P0 | U-01 | No visual verification was possible | Rendering in dark/light, Arabic RTL/English LTR, 360–1920 px, animation playback and comparison with the two reference images were never observed. This now covers every release 2 and release 3 screen as well (store, custody, evaluation, circulars, contracts, warnings, letters, finance, payroll, payslips). | The claims “visually cohesive”, “responsive” and “matches the references” are unproven. | Run a browser QA pass at 360, 768, 1280, 1920 px in both themes and directions; compare with the references; fix findings. |
| P0 | U-02 | Official logo and final typeface missing | Placeholder mark; Cairo vs Tajawal undecided. | Brand accuracy cannot be claimed. | Supply the SVG/PNG logo and decide the font. |

| P1 | U-08 | Contract/owner decisions that block exact conformance | (a) The complainant response has no field for the final decision, though decision 35 says the complainant sees it. Sign-out is mock-only. | Real channel and file behaviour is untested. | Integrate the hub, push, email and file endpoints. |
